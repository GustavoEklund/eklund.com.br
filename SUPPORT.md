# Getting help

| You want to                                | Go to                                                                                                                                   |
| ------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------- |
| Report a bug on the site or in the tooling | [Open an issue](https://github.com/GustavoEklund/eklund.com.br/issues/new/choose)                                                       |
| Suggest a change                           | [Open an issue](https://github.com/GustavoEklund/eklund.com.br/issues/new/choose) before you write code, so we agree on it first        |
| Ask how something works in the code        | [Discussions](https://github.com/GustavoEklund/eklund.com.br/discussions), after reading [`docs/architecture.md`](docs/architecture.md) |
| Report a security problem                  | [`SECURITY.md`](SECURITY.md), and never in a public issue                                                                               |
| Report a Code of Conduct problem           | [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md)                                                                                              |
| Talk to me about anything else             | gustavo@eklund.com.br, in Portuguese or English                                                                                         |

## Using this site as a starting point

The repository is open so that anyone can read how the site is built, learn from it and reuse the code under the [MIT license](LICENSE). It is not a template and it is not written to be cloned and deployed: the text, the career and the images are mine ([`NOTICE.md`](NOTICE.md)), and I do not give support for turning it into another person's site. The pieces that stand on their own are easy to lift, such as the status page, the trace viewer, the load test worker and the checks in `tools/`.
